# Contributing to ai-context-lint

Thanks for your interest in contributing to ai-context-lint!

## Getting Started

Clone the repository and install dependencies:

```bash
npm install
```

Build the project:

```bash
npm run build
```

Run the tests:

```bash
npm test
```

Run the CLI locally:

```bash
npm run dev -- ./test-repo
```

## Making Changes

1. Create a branch for your change.
2. Make your changes.
3. Add or update tests where appropriate.
4. Run the test suite.
5. Run the build.
6. Open a pull request with a clear description of the change.

## Pull Requests

Please keep pull requests focused on a single change whenever possible.

Include:

- What changed
- Why the change was needed
- How it was tested

## Reporting Issues

If you find a bug or have an idea for an improvement, please open a GitHub issue with enough detail to reproduce or understand the problem.

Thanks for contributing!
